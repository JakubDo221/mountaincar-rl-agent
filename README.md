# MountainCar RL Agent

Reinforcement Learning project using PyTorch and Gymnasium.
The agent learns to solve the MountainCarContinuous-v0 environment using the Cross-Entropy Method (CEM) and a neural network policy.

## Technologies
- Python
- PyTorch
- Gymnasium
- NumPy
- Matplotlib

## Features
- Reinforcement Learning
- Cross-Entropy Method (CEM)
- Neural network policy
- Environment simulation
- Training visualization
